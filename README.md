# Sustainable Polymer Manufacturing Group (SPMG) website

Live site: https://spmg-kfupm.github.io (update if the organisation name differs)

## Editing content
Use the admin panel at https://app.pagescms.org . No code needed.
Every save is recorded in this repository's history and can be undone.

## Where things live
- `index.html` : page design and layout
- `content/*.json` : all text (equipment, people, publications, news, materials, research, group info)
- `media/` : logo and photos
- `.pages.yml` : admin panel forms (owner only)

Hosted free on GitHub Pages from the `main` branch.
